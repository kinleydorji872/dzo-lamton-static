DDC JOYIG FONT  (output font: DDC Joyig, size 12)
================================================
The DDC fonts belong to the Dzongkha Development Commission (DDC), Bhutan, so they are not bundled.

1. Get "DDC Joyig" (DDC_Joyig.ttf) from the DDC website  https://www.dzongkha.gov.bt
   (Downloads / Fonts).  The free "DDC Uchen" font is also packaged as "fonts-ddc-uchen" on Debian/Ubuntu.
2. EITHER install the font on your computer / phone (double-click the .ttf → Install),
   OR copy the file into this folder and name it exactly:   DDC_Joyig.ttf
   (css/tokens.css already points to fonts/DDC_Joyig.ttf, so every visitor gets it automatically.)
3. Word downloads (.docx) are set to "DDC Joyig", 12 pt. The reader's computer needs the font
   installed to see it; otherwise Word shows a backup Tibetan font.
Until then the app shows Dzongkha using the backup font "Noto Serif Tibetan".
